##  Problem Overview
A published software package on registries like npm often does not match what developers reviewed and committed in source repositories. Injected installation scripts (`postinstall`), obfuscated files, and backdoor binaries pose massive supply-chain risks.

**WANNABE** answers one fundamental question:  
**Does the published package actually match its claimed source code?**

For our complete hackathon proposal, model justifications, threat model, and architecture, see [HACKATHON.md](HACKATHON.md).
